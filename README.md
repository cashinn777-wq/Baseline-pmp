# Baseline — PMP Drill

A situational-judgment drill for the PMI PMP exam, built on the **July 2026 Exam Content Outline**.

- 116 questions across all 26 ECO tasks
- Domain mix 33 / 41 / 26 (People / Process / Business Environment)
- ~60% adaptive and hybrid, matching PMI's current split
- Question formats: single-response, multiple-response, graphic-based, and case sets
- Logic drills for argument analysis and question-stem reading
- Spaced repetition, mistake journal, and confidence calibration

Runs entirely in the browser. No account, no tracking, no network calls at runtime.
Progress is stored locally on the device.

## Use

Open the deployed URL in Safari, then **Share → Add to Home Screen**.

## Build

`index.html` loads the data chunks (`d*.js`) and then `engine.js`, in order.
